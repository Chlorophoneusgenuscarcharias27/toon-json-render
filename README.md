## 📦 What It Does

toon-json-render helps with JSON data used in AI apps. It works as a drop-in TOON adapter for json-render, so you can use it in place of a normal JSON flow and keep the same app style.

Use it when you want to:

- make JSON use fewer LLM tokens
- keep your app in the same language and stack
- work with OpenUI-style interfaces
- handle streaming data in a clean way
- render JSON for AI chats, forms, and UI blocks
